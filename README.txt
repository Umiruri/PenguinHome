1.ゲーム概要

タイトル：おうちにかえろう
ジャンル：3D探索ゲーム
制作エンジン：Unity
プログラミング言語：C#
対応OS：Windows / MacOS / WEB
制作人数：1人

【ゲーム紹介】
『おうちにかえろう』はフィールドを探索しながらペンギンを見つけ、仲間にして家へ連れて帰る3D探索ゲームです。
フィールドを自由に探索し、ペンギンを仲間にしながら各地に配置されたイベントに挑戦します。
イベントではダイスによる判定を取り入れており、TRPGのような要素を楽しめるようにしています。
探索を通して仲間のペンギンを増やし、最後に探索結果を確認することが目標となります。



2.あそびかた・操作方法

【ゲームの基本的な流れ】
1.タイトル画面からゲームを開始します。
2.「はじめから」を選択して、セーブ名を入力します。
3.プレイヤーの能力値を決めます。
4.フィールドを探索します。
5.フィールドにいるペンギンを見つけて仲間にします。
6.フィールドに置かれているイベントに挑戦します。
7.家に帰り、探索を終了し、結果画面で成果を確認します。
8.「セーブ」を押すと、今回のゲームが保存されます。
9.「もう一度」を押すと、もう一度探索を開始します。
10.「タイトルへ戻る」を押すと、タイトル画面へ戻ります。
11.「つづきから」を押すと、入力したセーブ名・決めた能力値から再開できます。

【操作方法】
移動：W/A/S/Dまたは矢印キー
ジャンプ：Spaceキー
マウス：カメラ操作



3.ゲームシステム

【プレイヤーの能力値について】
ゲーム開始時に、以下の3種類の能力値を設定します。
つよさ
すばやさ
かしこさ
各能力値は合計30ポイントを目安に振り分けます。最低値はありませんが、すべて割り当てることをおすすめします。30ポイント未満でも設定できます。
各能力値はイベントの判定に使用します。

【ペンギンについて】
フィールドのペンギンを仲間にすると、プレイヤーに追従させることが出来ます。
仲間のペンギンは、探索中に一緒に行動します。

【イベントについて】
フィールドのイベント地点に触れることでイベントが発生します。
イベントはダイスによる判定を行い、成功・失敗によって結果が変化します。

【セーブ・ロードについて】
計3つのセーブスロットを利用できます。
セーブデータには、プレイヤーと仲間のペンギンの位置や向き・状態、イベントの進行状況、プレイ時間などを保存します。



4.動作環境・起動方法

【対応OSについて】
WindowsとMacOS、Web版となります。

【起動方法について】
1.配布してあるゲームフォルダを展開します。
2.フォルダ内のゲーム実行ファイル（Windowsの場合はexeファイル、MacOSの場合はappファイル）を起動します。
3.タイトル画面からゲームを開始します。

【セーブデータの保存場所について】
セーブデータはJSON形式で保存されます。
セーブスロットごとに保存されます。



5.制作環境・技術

【開発環境について】
ゲームエンジン：Unity6.6
プログラミング言語：C#
3D制作ツール：Blender5.0

・ペンギンの状態管理
・セーブ・ロード機能
・タイトル画面、メニュー画面、結果画面
